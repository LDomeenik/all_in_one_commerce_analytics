
# All-in-One Commerce Analytics


## Project Overview


이 프로젝트는 이커머스 데이터를 업로드하면 자동으로 분석을 수행하는 서비스입니다.

데이터를 업로드하면 컬럼 자동 매핑, 전처리, 분석 가능 여부 진단을 거쳐
KPI, 코호트, RFM, 상품 분석 등의 결과를 제공합니다.

이 프로젝트의 최종 목표는
이커머스 데이터를 넣으면 주요 분석을 자동으로 수행하는
All-in-One 분석 서비스를 구축하는 것입니다.
