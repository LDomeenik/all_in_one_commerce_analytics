
# 분석 가능 여부 진단 정책서

```
본 문서는 업로드된 데이터를 기반으로 
각 분석 모듈의 실행 가능 여부를 진단하기 위한 기준을 정의합니다.

본 프로젝트는 다양한 이커머스 데이터를 입력받으므로
데이터셋에 따라 일부 분석 모듈이 실행 불가능할 수 있습니다.

진단 기능은 사용자가 데이터를 업로드한 후
어떤 분석을 실행할 수 있는지 명확하게 안내하는 것을 목적으로 합니다.

본 문서는 다음 용도로 활용됩니다.

- 분석 가능 여부 진단 모듈 구현 기준
- 분석 모듈 활성화/비활성화 판단 기준
- 사용자에게 진단 결과 안내 기준

※ 본 문서는 MVP 기준으로 작성되었으며, 확장 분석 모듈 추가 시 진단 기준을 추가합니다.
```


---

## 1. 진단 설계 원칙

```
본 프로젝트의 분석 가능 여부 진단은 다음 원칙을 기반으로 설계합니다.

- 필수 컬럼 존재 여부를 실행 가능 여부의 유일한 기준으로 사용
- 결측 비율은 실행 가능 여부 판단에 사용하지 않음
- 예외적으로 필수 컬럼의 결측 비율이 100%라면 필수 컬럼이 존재하지 않는 것으로 판단
- 결측 비율은 참고 정보로 사용자에게 제공
- 분석 모듈별로 독립적으로 진단 수행
- 진단 결과는 분석 모듈 활성화/비활성화에 직접 활용
```

- **필수 컬럼 기반 진단**
	- 분석 모듈별 필수 컬럼이 모두 존재하면 실행 가능으로 판단
	- 하나라도 없으면 실행 불가로 판단
	- 필수 컬럼 기준은 [[Analytics Column Requirements]]를 따름

- **결측 비율은 참고 정보**
	- 결측 비율이 높더라도 실행 가능 여부에는 영향을 주지 않음
	- 결측 비율은 사용자가 데이터 품질을 판단하기 위한 참고 정보로 제공
	- 구조적 결측(예: 미배송 주문의 `delivered_date` 결측)을 오판하지 않기 위함
	- 예외적으로 필수 컬럼 중 결측 비율이 100%인 컬럼은 해당 컬럼이 존재하지 않는 것으로 판단

- **모듈별 독립 진단**
	- 각 분석 모듈은 독립적으로 진단
	- 하나의 모듈이 실행 불가여도 다른 모듈에는 영향을 주지 않음


---

## 2. 진단 기준


### 2.1 실행 상태 정의

| 상태    | 조건          | 설명             |
| :---- | ----------- | -------------- |
| 실행 가능 | 필수 컬럼 전체 존재 | 해당 분석 모듈 실행 가능 |
| 실행 불가 | 필수 컬럼 일부 누락 | 해당 분석 모듈 실행 불가 |

### 2.2 결측 비율 경고 기준

```
결측 비율은 실행 가능 여부와 무관하게 참고 정보로 제공합니다.
단, 높은 결측 비율은 사용자에게 주의 안내를 제공합니다.
```

| 결측 비율    | 표시    | 설명                       |
| :------- | ----- | ------------------------ |
| 0%       | 표시 없음 | 정상                       |
| 1% ~ 30% | 🟡 주의 | 일부 결측 존재                 |
| 30% 초과   | 🔴 경고 | 높은 결측 비율, 분석 결과 해석 주의 필요 |


---

## 3. 진단 결과 구조

| 항목                 | 설명                        |
| :----------------- | ------------------------- |
| `avaulable`        | 실행 가능 여부 (True / False)   |
| `status`           | 실행 상태 ("실행 가능" / "실행 불가") |
| `missing_columns`  | 존재하지 않는 필수 컬럼 목록          |
| `optional_missing` | 존재하지 않는 선택 컬럼 목록          |
| `null_rate`        | 존재하는 필수 컬럼별 결측 비율         |

